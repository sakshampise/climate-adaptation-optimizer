# UI Components (`components/`)

This directory houses modular, reusable Streamlit user interface components for the Climate Adaptation Investment Prioritization application.

---

## Structure & Responsibilities

- **`metric_cards.py`:** Key performance metric cards (Total resilience points, budget utilization, count of projects deployed).
- **`scenario_table.py`:** Comparative scenario matrix rendering results across policy presets.
- **`charts.py`:** Plotly-based visual analytics (multi-criteria trade-off radar, budget breakdown bar charts).
- **`provenance_banner.py`:** Reusable notice rendering provenance badges and data status disclaimers.
