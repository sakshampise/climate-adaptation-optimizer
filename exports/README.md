# Exports Directory (`exports/`)

This directory stores generated outputs from the Climate Adaptation Investment Prioritization platform.

---

## Output Categories

1. **Portfolio Allocation CSVs:** User-downloaded CSV records containing prioritized intervention packages for a specific budget tranche.
2. **Scenario Comparison CSVs:** Exported matrices comparing allocations across all four objective presets (*Flood Priority*, *Heat Priority*, *Balanced Resilience*, *Social & Climate Equity*).
3. **Execution Artifacts:** Timestamped optimization runs for reproducibility and audit logging.

All exported CSVs preserve the `data_status` column and include explicit disclaimers confirming that outputs are decision-support guidelines rather than executive municipal mandates.
