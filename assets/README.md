# Project Visual Assets (`assets/`)

This directory stores visual assets used in the application interface, documentation, and presentation materials.

---

## Asset Guidelines

- **Logos & Icons:** Municipal insignia, hackathon badges, climate hazard icons (flood, heat, nature-based solutions, infrastructure).
- **Format:** Prefer vector formats (`.svg`) or web-optimized `.png`.
- **Licensing:** Ensure all visual assets are free for open educational and civic demonstration use.
